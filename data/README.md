# Data files

Both dictionaries come unchanged from `symspellpy` 6.10.0 (MIT, https://github.com/mammothb/symspellpy),
which ships them from the original SymSpell (MIT, https://github.com/wolfgarbe/SymSpell).

- `frequency_dictionary_en_82_765.txt`: `term count` per line.
- `frequency_bigramdictionary_en_243_342.txt`: `term1 term2 count` per line.

`tests/fixtures/symspellpy/` holds symspellpy's own test fixtures, also unchanged, with its license.
